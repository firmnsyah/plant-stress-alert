# Protokol Eksperimen (Templat)

- Spesies: *Capsicum annuum* L.
- Perlakuan: kontrol, panas, salinitas, kekeringan.
- Ulangan dan lama pengamatan: tetapkan sebelum pengambilan data.
- Jam pengukuran: tetap setiap hari.
- Hari 0: baseline sebelum cekaman.
- Catat hari layu pertama dan skor layu setiap observasi.

Tingkat suhu/lama panas, konsentrasi NaCl, kapasitas lapang untuk kekeringan, alat bioelektrik, dan definisi skor layu harus diisi oleh peneliti sebelum data dipakai untuk kalibrasi.
